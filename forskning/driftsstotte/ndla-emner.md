# NDLA Driftsstøtte VG2 — Emneoversikt

## Hovedtemaer på NDLA Driftsstøtte

### 1. Nettverk
- Komponentene i datanettverk (svitsj, ruter, AP, kablage)
- IPv4 (adresser, subnetting, CIDR, binært/desimalt)
- IPv6
- NAT (Network Address Translation)
- TCP, UDP og porter
- DNS-oppslag
- DHCP
- Ruter (funksjon og konfigurasjon)
- Virtuelt lokalnettverk (VLAN, IEEE 802.1Q)
- Nettverkslagring (NAS)
- Trådløse nettverk

### 2. Operativsystem og server
- Klargjøre maskin til server (BIOS/UEFI, virtualisering)
- Enkelt oppsett av labnettverk

### 3. Virtualisering
- Hypervisorer, virtuelle maskiner
- Sky vs on-prem

### 4. Nettverkstjenester
- DHCP, DNS, web, e-post, filserver

### 5. Sikkerhet
- Trusler og sårbarheter
- Brannmur
- Kryptering
- Risikoanalyse

### 6. Bærekraft
- Energiforbruk, miljøavtrykk

## Eksisterende oppgaver på NDLA
- Oppgaver om IP-adresser (binært, CIDR, subnettmaske)
- Oppgaver om IPv6
- Oppgaver om VLAN (case-baserte)
- Oppgaver om nettverkskomponenter

## Hva NDLA-oppgavene mangler
- Større tverrfaglige case-oppgaver
- IP-planlegging for reelle bedriftsscenarioer
- Nettverkskart-tegning med fysisk + logisk
- Dokumentasjon og refleksjon som en integrert del
