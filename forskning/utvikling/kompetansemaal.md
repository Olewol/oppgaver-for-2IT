# Utvikling VG2 — Kompetansemål (ITK02-01)

## Kjerneelementer som utvikling dekker
- Løsningsarkitektur og systemutvikling
- Utviklingsprosesser og kreativ problemløsing
- Informasjonssikkerhet

## Kompetansemål — 10 stk

### km-01: Vurdere fordeler og ulemper ved ulike programmeringsspråk og velge/anvende relevante språk og algoritmer
Python, JavaScript, C#, Java — styrker/svakheter, algoritmer, problemløsing.

### km-02: Lage og begrunne funksjonelle krav til en IT-løsning basert på behovskartlegging
Behovsanalyse, kravspesifikasjon, funksjonelle/ikke-funksjonelle krav.

### km-03: Vurdere brukergrensesnitt til IT-tjenester og designe tjenester tilpasset brukeres behov
UI/UX-prinsipper, brukertesting, universell utforming, tilgjengelighet.

### km-04: Gjøre rede for hensikten med teknisk dokumentasjon og utarbeide teknisk dokumentasjon
README, API-dokumentasjon, arkitekturdiagram, kommentarer, docs-as-code.

### km-05: Beskrive og anvende relevante versjonskontrollsystemer i utviklingsprosjekter
Git, branching, merging, pull requests, GitHub/GitLab.

### km-06: Designe og implementere IT-tjenester med innebygget personvern
Privacy by design, data-minimering, personvern i arkitektur, samtykke.

### km-07: Analysere digitale trusler, verdier og sårbarheter og utvikle applikasjoner med innebygget sikkerhet
Security by design, input-validering, autentisering, autorisering, OWASP.

### km-08: Anvende relevant testmiljø og utføre testing tilpasset IT-løsningen
Enhetstesting, integrasjonstesting, brukertesting, testplan.

### km-09: Modellere og opprette databaser for informasjonsflyt i systemer
ER-modellering, SQL, normalisering, relasjonsdatabaser.

### km-10: Beskrive ulike datalagringsmodeller og metoder for å hente ut og sette inn data
SQL vs NoSQL, API-integrasjon, REST, JSON, ORM.
